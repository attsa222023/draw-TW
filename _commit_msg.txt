Auto-scroll to the result panel when a round finishes

The draw game already does this on finishBtn (resultPanel.scrollIntoView),
but the placename page never did -- the result panel sits well below
the question/tools/map/tier-picker stack, so a player who just
answered the last question (daily or special) had no on-screen cue
they were actually done; they had to notice and scroll down
themselves. New scrollToResultPanel() helper, called from both
finishChallenge() and finishSpecialRound() right after renderResults()
unhides the panel, wrapped in requestAnimationFrame so the layout pass
from clearing `hidden` has already happened -- same pattern as the
draw game's own handler.

Deliberately NOT added to showArchivedResult() (loading straight into
an already-completed day) -- an animated scroll firing on page load
itself, before the player has done anything, would read as jarring
rather than helpful.
